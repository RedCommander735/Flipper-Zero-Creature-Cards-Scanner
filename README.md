This project is entirely vibecoded with GLM 5.3 because I dont know much about flipper zero development.
I would have attempted to code this myself, but the resources and documentation for flipper zero development are basically nonexistent, so I was more or less forced to do it this way.

The Github repo only serves the purpose to share the app with other people who might find this useful.

## Creature Cards Scanner
This project is a app for the flipper zero to rapidly scan and save [Creature Cards](https://cc.mysteryhack.com) with a distinct name for each card, so they can easily be reproduced later.
